# Prompts de texto

## Criação do nome

```text
Você é um roteirista de podcasts de tecnologia. Sugira nomes curtos para um podcast brasileiro sobre dados e Databricks.

Regras:
- use no máximo duas palavras;
- o nome deve funcionar para outros episódios sobre engenharia de dados;
- mantenha um tom profissional e simples;
- liste oito opções.

Não use:
- slogans motivacionais;
- trocadilhos longos;
- promessas exageradas;
- nomes de pessoas.
```

Nome selecionado: **DataCast**.

## Criação do roteiro

```text
Você é um roteirista de podcast. Escreva um episódio introdutório, em português brasileiro para o podcast "DataCast".

Título do episódio: "Primeiros passos com Databricks".
Público-alvo: pessoas sem experiência com a plataforma.
Duração máxima: três minutos.

Explique:
1. o que é Databricks;
2. o conceito de lakehouse;
3. as camadas bronze, prata e ouro da arquitetura medalhão;
4. para que servem notebooks;
5. um fluxo inicial de estudo.

Regras:
- use frases curtas e adequadas para narração;
- confira os conceitos na documentação oficial do Databricks;
- não use estatísticas;
- não invente funcionalidades;
- não use tom publicitário;
- não imite apresentadores reais;
- não ultrapasse três minutos.
```
